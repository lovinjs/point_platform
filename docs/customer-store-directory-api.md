# 客户端合作门店目录

合作门店目录供 H5 和未来小程序共用。门店信息属于公开营业信息，因此以下两个只读接口不要求客户登录；其他 `/api/v1/customer/**` 接口仍然需要客户 JWT。

本阶段复用现有商户和门店数据，不需要新增 Flyway 脚本。

## 门店列表

~~~http
GET /api/v1/customer/stores?pageNum=1&pageSize=20&keyword=测试
~~~

- `pageSize` 最大为 50。
- `keyword` 可按门店名称或地址模糊查询，最多 100 个字符。
- 仅返回商户状态为 `ACTIVE` 且门店状态为 `ACTIVE` 的门店。
- 排序规则为门店名称、门店 ID 升序。

## 门店详情

~~~http
GET /api/v1/customer/stores/{storeId}
~~~

门店或所属商户不再有效时统一返回“门店不存在”，避免客户端继续展示已停业门店。

## 公开字段

~~~json
{
  "storeId": 1,
  "storeCode": "STORE-001",
  "storeName": "测试合作门店",
  "merchantId": 1,
  "merchantName": "测试合作商户",
  "address": "测试市测试区合作路1号",
  "contactPhone": "13800138000"
}
~~~

接口不会返回签约主体、统一社会信用代码、合作协议编号、商户负责人或后台员工信息。

## H5 功能

- 首页提供“合作门店”入口，未登录也可以使用。
- 列表支持搜索、下拉刷新和分页加载。
- 支持查看门店详情、拨打门店电话和复制门店地址。
- 当前数据库尚未保存经纬度，因此暂不提供地图导航；后续增加经纬度并校验后再接地图能力。
