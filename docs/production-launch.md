## 5. 正式服务号网页授权

在微信公众平台登录已经认证的正式服务号，查找：

`设置与开发 → 公众号设置 → 功能设置 → 网页授权域名 → 设置`

不同界面版本可能调整菜单，可按「网页授权域名」字段查找；如果未找到，可提供不含 AppSecret 的界面截图。这里使用服务号 H5 网页授权，不是微信开放平台的网站扫码登录，也不需要先申请微信支付。

正式网站根目录确认后，从该设置窗口下载微信给出的域名校验文件，原名、原内容上传到消费者正式网站根目录，确认指定文件公开可访问，再保存 `point.qiongyintech.com`。不填写协议、路径、端口或后台域名，不自行编造校验文件内容。

准备后端目标配置，待正式数据空间和切换窗口确认后再填写服务器环境文件，不现在应用：

```dotenv
PLATFORM_WECHAT_H5_ENABLED=true
PLATFORM_WECHAT_H5_APP_ID=填写正式服务号AppID
PLATFORM_WECHAT_H5_APP_SECRET=填写正式服务号AppSecret
PLATFORM_WECHAT_H5_CALLBACK_URL=https://point.qiongyintech.com/api/v1/h5/auth/wechat/callback
PLATFORM_H5_BASE_URL=https://point.qiongyintech.com
PLATFORM_WECHAT_H5_SCOPE=snsapi_userinfo
```

正式号和测试号按 AppID/OpenID 匹配，不把测试用户或已绑定的测试手机号当作自动迁入正式账号。正式库从零建立，首次微信登录后重新绑定手机号。

1. 保留预发布库和配置，另建正式数据库、专用数据库账号与独立 Redis 逻辑空间；Redis 逻辑空间不能代替 Redis 本身的认证及网络限制。
2. 生成新的后台和消费者 JWT 密钥，保持 Flyway 迁移和校验；核查 MySQL TLS、短信限额、备份和恢复安排。
3. 在切换窗口先将两个预发布网站的 API 代理停用或维护化，保留 ACME 验证。否则预发布域名会通过同一个 8888 端口访问正式账本。停止测试人员操作，不在旧库和新库之间来回试写。
4. 切换 Java 正式数据空间、正式服务号和短信配置，初始化新超管，然后关闭初始化开关并清除初始化密码，保留永久 JWT 密钥。
5. 为两个正式域名分别配置消费者及管理端最小代理；消费者域名继续屏蔽后台，后端/数据库/Redis 不新增公网端口。
6. 确认 UP、空库角色和必要业务参数、正式域名匿名访问权限正常；最后启用正式 H5 授权开关、重建和发布匹配版本的两个前端包。
